# Interview Command Center

An adaptive mock interview simulator for **any finance-adjacent role** — not a fixed list. Type in what you're preparing for (Equity Research, Actuarial Analyst, Tax Accounting, Credit Risk, Private Equity, or anything else) and run a live 3-round interview with genuinely relevant, AI-generated questions, adaptive follow-ups that dig into what you actually said, and structured feedback. Dark, finance-terminal aesthetic, built with vanilla HTML/CSS/JS. No backend, no build step. Companion project to [risk-command-center](https://github.com/Nnd1106/risk-command-center), [valuation-command-center](https://github.com/Nnd1106/valuation-command-center), [market-simulator](https://github.com/Nnd1106/market-simulator), and [company-deep-dive](https://github.com/Nnd1106/company-deep-dive).

**Live demo:** https://nnd1106.github.io/interview-command-center/

## The three rounds

1. **Technical Round 1 — Foundations.** Three foundational, theory-based questions testing core concepts for the exact role you typed.
2. **Technical Round 2 — Applied & Case.** A scenario question, a guesstimate/estimation question, and a logical-reasoning puzzle — role-flavored wherever a natural fit exists.
3. **HR Round — Behavioral.** Strengths & weaknesses, why this field, a difficult situation you handled, and career goals.

After every core question, the AI reads your actual answer and asks **one genuine follow-up that digs into something specific you said** — pushing on a vague claim, asking for a concrete example, or probing an assumption — the way a real interviewer would, not a generic "next question." You then get structured feedback (what you covered well, what was missing or wrong, one specific way to improve) after both the core answer and the follow-up answer. At the end, an overall performance summary is generated from the whole transcript.

Nothing is a fixed question bank — every question is generated live for the role you typed, in real time.

## Privacy — the whole point of building this as a static page

- **No resume upload, anywhere.** Not offered, specifically so nothing like that can ever be sent anywhere.
- **No server, no database.** This is a static page on GitHub Pages. There is nothing on the other end to save your answers to.
- **In-memory only.** Your role, every answer, and every piece of feedback live in a plain JavaScript variable in this browser tab. Nothing is written to `localStorage`, `sessionStorage`, a cookie, or anywhere else. Close or reload the tab and it's gone — verified directly: after a full 20-question mock interview, `localStorage` contains exactly one key (your Gemini API key, if you saved one) and `sessionStorage` is empty.
- **Minimal API payload.** Each call to Gemini sends only the role you typed, the current round/question text, and the answer you typed — nothing else. No name, no email, no browser fingerprint, no resume. This is enforced by construction: every prompt builder in `assets/js/interview.js` takes only `{ role, question, answer }`-shaped arguments, and `assets/js/aiClient.js` sends exactly the prompt string it's given, nothing more.
- **Your API key stays local.** Stored only in this browser's `localStorage`, sent only to Google's Gemini endpoint — never anywhere else, never logged.

## AI: Google Gemini (free tier)

Questions, follow-ups, and feedback are generated by the **Gemini API** via [Google AI Studio](https://aistudio.google.com/apikey) — free signup, **no credit card, no billing account attached, ever.** AI-Studio-issued keys physically cannot incur a charge; enabling billing is a separate, deliberate opt-in behind Google's own Vertex AI upgrade flow that this app never touches. Confirmed directly (not assumed): the endpoint returns `Access-Control-Allow-Origin` reflecting the calling origin, so it's callable straight from a static page with no proxy.

Uses `gemini-2.0-flash` with structured JSON output (`responseSchema`) so every response is parsed reliably — no fragile markdown-scraping. One full mock interview costs about 31 API calls (question + feedback/follow-up + feedback, per core question, plus one closing summary), issued one at a time as you progress through the interview — comfortably inside the free tier's rate limits for a single session. If you hit a rate limit or an invalid-key error, the app shows the specific error with a retry button rather than failing silently.

## Any role, genuinely — not a fixed list

There's no hardcoded role list or canned question bank. The role you type flows directly into every prompt sent to Gemini; foundational questions explicitly avoid repeating ones already asked in the same round. Verified across deliberately different fields (Tax Accounting, Actuarial Analyst, Equity Research, Private Equity, Credit Risk, Investment Banking, FP&A) that the generated questions are genuinely distinct and field-appropriate, not generic filler with the role name swapped in.

## Pressure, without a data-loss bug

A visible countdown timer runs per question (2:30), turning amber then red as it nears zero — matching real interview pressure. It never force-submits or deletes what you've typed; at zero it just shows "time's up" so you can wrap up on your own terms.

## Running locally

No build step:

```bash
npx http-server -p 8080
# then open http://localhost:8080
```

## Stack

Pure HTML/CSS/JS. No frameworks, no bundler, no backend, no analytics. Nothing here is a substitute for real interview prep with a human, and no score or transcript is ever saved anywhere but your own screen, for as long as this tab stays open.
