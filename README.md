# Interview Command Center

A mock interview simulator for **any finance-adjacent role** — not a fixed list. Type in what you're preparing for (Equity Research, Actuarial Analyst, Tax Accounting, Credit Risk, Private Equity, Markets & Trading, Strategy & Consulting, or anything else) and run a live 3-round interview. Choose your mode up front: genuinely adaptive AI, or instant no-setup practice. Dark, finance-terminal aesthetic, built with vanilla HTML/CSS/JS. No backend, no build step. Companion project to [risk-command-center](https://github.com/Nnd1106/risk-command-center), [valuation-command-center](https://github.com/Nnd1106/valuation-command-center), [market-simulator](https://github.com/Nnd1106/market-simulator), and [company-deep-dive](https://github.com/Nnd1106/company-deep-dive).

**Live demo:** https://nnd1106.github.io/interview-command-center/

## Two modes, chosen up front

The very first screen asks which one you want — no surprises mid-interview about speed or personalization:

|  | **Adaptive AI Interview** | **Quick Practice** |
|---|---|---|
| Questions | Generated live by Google's Gemini API, tailored to your exact role | Pulled from a pre-written bank matched to the closest of several broad categories |
| Follow-ups | Dig into something specific you actually said | Simple generic probes ("can you elaborate with an example?") |
| Feedback | AI-graded: covered well / missed / one way to improve | A self-assessment checklist you grade yourself against |
| Speed | ~20–40s per step (longer if Gemini's free tier is rate-limited) | Instant — zero network calls |
| Setup | Needs a free Gemini API key (no card, ~20s) | None — no key, ever |

Both modes run the identical structure underneath — same three rounds, same round-by-round flow, same visible per-question timer.

## The three rounds

1. **Technical Round 1 — Foundations.** Three foundational, theory-based questions testing core concepts for the exact role you typed.
2. **Technical Round 2 — Applied & Case.** A scenario question, a guesstimate/estimation question, and a logical-reasoning puzzle — role-flavored wherever a natural fit exists.
3. **HR Round — Behavioral.** Strengths & weaknesses, why this field, a difficult situation you handled, and career goals.

After every core question, you get one follow-up that builds on it (AI-crafted in Adaptive mode, a generic probe in Quick Practice), then structured feedback or a self-assessment checklist. At the end, an overall performance summary — AI-generated in Adaptive mode, computed from your own checklist results in Quick Practice.

## Privacy — the whole point of building this as a static page

- **No resume upload, anywhere.** Not offered, specifically so nothing like that can ever be sent anywhere.
- **No server, no database.** This is a static page on GitHub Pages. There is nothing on the other end to save your answers to.
- **In-memory only.** Your role, every answer, and every piece of feedback live in a plain JavaScript variable in this browser tab. Nothing is written to `localStorage`, `sessionStorage`, a cookie, or anywhere else. Close or reload the tab and it's gone — verified directly: after a full 20-question mock interview, `localStorage` contains exactly one key (your Gemini API key, if you saved one, in Adaptive AI mode) and `sessionStorage` is empty.
- **Minimal API payload (Adaptive AI mode only).** Each call to Gemini sends only the role you typed, the current round/question text, and the answer you typed — nothing else. No name, no email, no browser fingerprint, no resume. Enforced by construction: every prompt builder in `assets/js/interview.js` takes only `{ role, question, answer }`-shaped arguments.
- **Quick Practice makes zero network calls, period.** Verified directly by actively blocking every request to Gemini's endpoint during a full 20-question session and confirming the call count stays at exactly 0 throughout.
- **Your API key stays local.** Stored only in this browser's `localStorage`, sent only to Google's Gemini endpoint — never anywhere else, never logged.

## AI: Google Gemini (free tier, Adaptive mode only)

Questions, follow-ups, and feedback are generated by the **Gemini API** via [Google AI Studio](https://aistudio.google.com/apikey) — free signup, **no credit card, no billing account attached, ever.** AI-Studio-issued keys physically cannot incur a charge; enabling billing is a separate, deliberate opt-in behind Google's own Vertex AI upgrade flow that this app never touches. Confirmed directly (not assumed): the endpoint returns `Access-Control-Allow-Origin` reflecting the calling origin, so it's callable straight from a static page with no proxy.

Uses `gemini-2.0-flash` with structured JSON output (`responseSchema`) so every response is parsed reliably — no fragile markdown-scraping. One full mock interview costs about 31 API calls (question + feedback/follow-up + feedback, per core question, plus one closing summary), issued one at a time as you progress — comfortably inside the free tier's rate limits for a single session, and each step is honestly labeled up front as taking roughly 20–40 seconds so there's no surprise mid-interview.

**Rate-limit resilience — the interview never fully breaks:**
- Every call is spaced at least 1.2s apart (invisible in normal use — you're reading and typing far slower than that — but it stops a burst of calls from tripping Gemini's short-window cap).
- A UI action can't fire a call twice: the Start and Continue buttons disable themselves synchronously the instant they're clicked, so a fast double-click can't send two concurrent requests for what should be one question — verified directly by forcibly double-clicking and confirming exactly one request fires.
- On a rate limit or network hiccup, the app retries automatically once, backed off by whatever wait time Gemini itself reports (or a sensible default) — visibly, with a live countdown, not a silent stall.
- If that retry *also* fails — two in a row — the app falls back to the same static per-category question bank Quick Practice uses (or, for feedback, an honestly-labeled placeholder instead of fabricating a read on your answer) so the interview keeps moving. It always says so plainly when this happens, with a visible "Offline backup" tag; nothing pretends to be live AI when it isn't.

## Quick Practice's question bank

No AI, no network, no API key — just a small hand-written set of questions per broad category (Equity Research, Accounting & Tax, Actuarial & Insurance, Investment Banking, Risk, Private Equity, Markets & Trading, Strategy & Consulting, FP&A/Corporate Finance, and a general-finance fallback), matched by keyword against whatever role you typed. The matched category is shown on screen so you can see how your role was classified. It's a genuinely useful, instant practice set — not a substitute for the tailored depth of Adaptive AI mode, which the mode-select screen says plainly.

## Any role, genuinely — not a fixed list

Neither mode hardcodes a role list. In Adaptive AI mode, the role you type flows directly into every prompt sent to Gemini; foundational questions explicitly avoid repeating ones already asked in the same round. In Quick Practice, the role is matched against the closest category via keyword rules, with a general-finance set as the fallback for anything unmatched. Verified across deliberately different fields (Tax Accounting, Actuarial Analyst, Equity Research, Private Equity, Credit Risk, Investment Banking, Strategy Consulting, Insurance Underwriting) in both modes that the resulting questions are genuinely distinct and field-appropriate, not generic filler with the role name swapped in.

## Pressure, without a data-loss bug

A visible countdown timer runs per question (2:30), turning amber then red as it nears zero — matching real interview pressure, in both modes. It never force-submits or deletes what you've typed; at zero it just shows "time's up" so you can wrap up on your own terms.

## Running locally

No build step:

```bash
npx http-server -p 8080
# then open http://localhost:8080
```

## Stack

Pure HTML/CSS/JS. No frameworks, no bundler, no backend, no analytics. Nothing here is a substitute for real interview prep with a human, and no score or transcript is ever saved anywhere but your own screen, for as long as this tab stays open.
