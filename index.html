🔒 Privacy guarantee

  • No resume upload. This tool doesn't offer one, specifically so nothing like that can ever be sent anywhere.
  • No server, no database. This is a static page — there is nothing on the other end to save your answers to, even if we wanted to.
  • In-memory only. Your role, answers, and feedback live in this browser tab's memory for this session and vanish the moment you close or reload the tab.
  • Minimal API payload. Each answer you type is sent only to Google's Gemini API — along with the role you entered and the current question's text — to generate feedback and a follow-up. No name, no identifying info, nothing else is ever included.
  • Your API key stays local. If you save a Gemini key below, it's stored only in this browser's localStorage and sent only to Google's API — never anywhere else.
