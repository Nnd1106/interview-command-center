🔒 Privacy guarantee

  • No resume upload. This tool doesn't offer one, specifically so nothing like that can ever be sent anywhere.
  • No server, no database. This is a static page — there is nothing on the other end to save your answers to, even if we wanted to.
  • In-memory only. Your role, answers, and feedback live in this browser tab's memory for this session and vanish the moment you close or reload the tab.
  • Minimal API payload (Adaptive AI mode only). Each answer you type is sent only to Google's Gemini API — along with the role you entered and the current question's text — to generate feedback and a follow-up. No name, no identifying info, nothing else is ever included.
  • Quick Practice mode makes zero network calls. Everything — questions, follow-ups, and your self-assessment — happens entirely in this browser tab.

Choose how you want to practice

Both modes run the same structure — three rounds, a visible timer per question, the same round-by-round flow. The difference is where the questions and feedback come from, and what that costs you in time and personalization.

Mode 1

Adaptive AI Interview

More realistic, more adaptive — and slower.

  • Every question is generated live by Google's Gemini API, tailored to the exact role you type — not a fixed bank.
  • Follow-ups dig into something specific you actually said, the way a real interviewer probes a vague or weak point.
  • Feedback is AI-graded: what you covered well, what you missed, one specific way to improve.
  • Each question or feedback step can take roughly 20–40 seconds to generate — longer if Gemini's free tier is rate-limited (it retries automatically with a visible countdown, then falls back to a backup question rather than getting stuck).
  • Requires a free Google AI Studio API key — no card, about 20 seconds to set up.
Speed~20–40s per step
PersonalizationHigh — genuinely adaptive
Mode 2

Quick Practice

Faster, zero setup — and less personalized.

  • Questions come from a pre-written bank, matched to the closest of several broad categories (Equity Research, Accounting & Tax, Actuarial, Risk, Investment Banking, Private Equity, Markets & Trading, Strategy & Consulting, FP&A, and more).
  • Every question appears instantly — no waiting, no API calls, ever.
  • Follow-ups are simple, generic probes (e.g. "can you elaborate with a specific example?").
  • Feedback is a self-assessment checklist you grade yourself against, not AI-graded.
  • No API key needed at all.
SpeedInstant
PersonalizationLower — generic bank + self-grading
